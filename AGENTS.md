# Instrucciones para LEVO

Aplicación Next.js 16 de rutas de mountain bike con mapas interactivos.
Stack: Next.js 16, React 19, Leaflet/MapLibre, Supabase, Turf.js.

## Prioridades
1. No romper funcionalidad existente (mapas, rutas, auth).
2. Antes de modificar, analizar estructura del proyecto.
3. Ejecutar `npm run lint` y `npm run build` tras cambios.
4. No modificar variables de entorno ni esquema de Supabase.
5. Mantener estilos actuales salvo orden explícita.
6. Si hay duda entre refactor grande o fix pequeño, aplicar fix pequeño.
7. No borrar archivos sin justificarlo.
8. No hacer push salvo orden explícita.
